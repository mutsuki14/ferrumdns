# Web 管理控制台

控制台随 FerrumDNS 二进制一起发布，通过 `api.http` 指定的端口访问。前端不依赖 CDN，不需要单独运行 Web 服务，也没有生产环境的 npm 构建步骤。

## 启动

```sh
cargo run --locked -- start -c examples/dev.yaml
```

打开 `http://127.0.0.1:9090/`。已有自定义配置只需要启用管理端口：

```yaml
api:
  http: 127.0.0.1:9090
```

首次启用或修改管理端口后需要重启。替换程序二进制即可更新内嵌界面。

## 功能

| 页面 | 可执行操作 |
|---|---|
| 运行概览 | 查看查询总数、实时 QPS、缓存命中率、平均耗时、处理统计和监听配置；选择 1/5/15 分钟趋势窗口 |
| 查询调试 | 选择 DNS 类型和入口，设置模拟客户端 IP/ECS，查看结构化记录、RCODE、缓存命中、插件轨迹，复制 JSON |
| 插件与规则 | 按名称、类型筛选当前插件，选择插件作为调试入口 |
| 缓存管理 | 查看各缓存当前条目及累计命中；确认后清理指定缓存或全部缓存 |
| 服务配置 | 查看程序版本、默认入口、监听地址、超时、TLS 和上游端点摘要，打开 Prometheus 指标 |

示例配置中可查询 `router.lan`、`nas.lan` 和 `ads.example.com`。自定义配置可能没有这些记录，请使用实际配置的域名。

配置页面是只读视图。修改规则请编辑 YAML，运行 `ferrumdns check -c config.yaml` 后发送 SIGHUP。监听器、入口、API、日志或 TLS 证书变更仍需要重启。

## 数据含义

- 每 3 秒获取一次真实 API 数据；可以关闭自动刷新并手动更新。隐藏浏览器标签页时暂停采样。
- QPS 使用两次采样的查询数差除以间隔秒数。首次采样、重载和断线重连时重新建立基线。
- 图表只保存当前页面最近 15 分钟的采样，刚打开时不会出现虚构的历史流量。
- 命中率为 `cache_hits / (cache_hits + cache_misses)`。未发生缓存查找时显示 `—`；多次缓存查找按后端计数口径累计。
- 平均响应时间将 `avg_latency_us` 转为毫秒。调试查询也计入后端统计。
- 统计属于当前 Runtime，规则重载后重置。清理缓存只清记录，不重置累计计数。
- 查询历史最多保留 10 条，位于当前页面内存中；刷新页面即清除，不写入浏览器持久存储。
- 连接失败时保留上次成功同步的数据显示时间与错误，不将离线误显示为零流量。

## 接口和访问

保留原有 `/health`、`/metrics`、`/api/stats`、`/api/plugins`、`/api/query` 与 `/api/cache/flush`。

新增 `GET /api/system`：返回版本、每代 Runtime 的稳定标识、默认入口、监听配置、插件类型与上游端点摘要。上游摘要移除用户名、密码、路径、查询参数和片段，不返回原始 YAML、证书文件路径或规则文件内容。

`POST /api/query` 在旧字段基础上增加 `records` 数组：

```json
{"name":"router.lan.","ttl":60,"type":"A","data":"10.0.0.1"}
```

单独清理一个缓存：

```sh
curl -X POST http://127.0.0.1:9090/api/cache/flush \
  -H 'Content-Type: application/json' -d '{"tag":"cache"}'
```

`{}` 或空请求体仍可清理全部缓存。未知 tag 或格式错误不会清理缓存。

控制台沿用现有管理 API 的信任边界，没有内置用户账号。默认保持回环监听；远程管理可使用 SSH 转发或带认证的反向代理。代理需保留原始 `Host`，以供浏览器写请求的来源校验。配置与调试轨迹属于管理信息。

页面设置同源 CSP、防嵌入、禁止 MIME 嗅探及 no-store。浏览器跨源写请求被拒绝；不附带浏览器来源头的既有管理脚本保持兼容。这些措施不能替代认证。

## 开发与验证

`web/` 保存 HTML、CSS、原生 JavaScript 和 SVG。Rust 通过 `include_str!` 嵌入资源；编辑这些文件后需要重新编译 Rust 才能更新运行中的界面。

```sh
# 服务与 HTTP 集成回归；不需要 Node.js
cargo test --all --locked
cargo +1.88.0 test --all --locked

# 前端开发检查：Node.js 24.15+，只安装开发依赖
npm ci
npm test
npm run format:check
```

JS 单元测试验证速率计算、配置代切换、IP/ECS 校验、过滤等逻辑。DOM 测试使用本地受控数据检查真实页面的表单、导航、错误、确认操作与安全文本渲染；不会启动浏览器或访问外部服务。Rust HTTP 测试验证真实管理接口、静态响应与缓存操作。

发布前仍建议在目标浏览器上检查桌面、窄屏导航和复制行为。DOM 测试不验证浏览器实际布局与绘制。
